1. 위 입력창의 IP 숫자를 클릭해 키보드로 직접 수정합니다.
2. 동일 포트 내 장비끼리는 앞 세 자리(서브넷)를 일치시키고, 마지막 호스트 번호는 중복되지 않게 설정합니다.

5. 카메라 IP의 네번째 숫자는 기본으로 135, 프로젝터 IP의 마지막 4번째 숫자는 '10'으로 고정 바랍니다.

ATM Robot Vision 트러블슈팅 요약 항목 클릭 시 펼침
1. AITZ 3D 스캐너 LED 점등 확인 (p.4)▾
PWR: 전원 TRX: 스캔중 LNK: 5초 점멸 STA: 통신상태
• 정상 부팅 순서: TRX 노랑 → TRX 초록 → PWR·LNK 초록 / STA 노랑 → PWR 초록 점등(연결 완료).
• 전면 LPF(Low Pass Filter)는 일반 유리가 아니므로 손 접촉 금지, 렌즈 와이프로만 세척합니다.
2. 하드웨어 연결 끊김 & 로그 조치 (p.8~13)▾
• 1차 즉시 복구: 하단 상태바의 적색 탭(PLC, SCANNER, ROBOT)을 Ctrl + 더블클릭하여 재연결 시도.
• 로그 "physically removed": 99% LAN/전원 케이블 단선 또는 커넥터 풀림 → RJ45·M12 체결 확인.
• 프로젝터 [EVENT_DISCONNECTED]: 펌웨어 충돌 → PC 랙 후면 스캐너 CP 전원을 20초 이상 내린 후 재부팅.
3. 네트워크 1.0Gbps 속도 & 랜카드 점검 (p.14)▾
• 제어판 어댑터 상태에서 링크 속도가 1.0 Gbps인지 확인 (속도 저하 시 3D 데이터 취득 실패 → 케이블 교체).
• PC 후면 랜포트 LED: 정상(초록/주황 점멸) / 통신이상(초록/초록 또는 소등).
• AbeoSCAN 테스트 시에는 반드시 현장 프로그램(ATMC)을 먼저 종료해야 합니다.
4. 공정 판정 NG (FIT / OVL / Limit 초과) (p.20~25)▾
• OVL 낮음 / FIT 높음: 기준 모델 대비 대상물 형상 변형, 조명 간섭 또는 스캐너 LPF 오염 점검 후 재스캔.
• Shift Limit 초과 NG: 로봇 경로 간섭 방지를 위한 안전 허용치 초과 상태 → 대상물 정위치 정렬 후 재기동.
• 스캐너 물리적 충격·교체 시에는 원점 보정(Eye correction matrix)을 수행합니다.
